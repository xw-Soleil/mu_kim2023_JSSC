## 第二部分:Stage B 建库冒烟

### B.1 只读检查发现

| 项 | 发现 |
|---|---|
| tf Tile | `unit` 0.135×0.900、`gaunit` 0.540×0.900 —— 高度与库一致,**宽度是 p135 系默认,不匹配本库** |
| cell LEF SITE | 引用 `core`×966、`gacore`×54、`bcore`×24,**定义 0 个** |
| 宽度证据 | 966 个 core 单元宽度全为 **0.140** 整数倍(0.135 只匹配 39 个);54 个 GA(BWP30P140)全为 **0.420** 倍;24 个双高(ISOSR*/LVLLH*)宽 0.140 倍、高 1.800 |
| 额外发现 | cell LEF 引用 `VIA12_square`×3213、`VIA12_slot`×1434,tf ContactCode 命名体系不同(VIA12_1cut 等),LEF 读入必须有 via 定义 |

### B.2 过程(全部经 `snps_no_udev.sh` 包装;裸调 icc2_lm_shell 在 SCL license
checkout 的 libudev 路径段错误 exit 139,与 65nm 已知问题同源)

1. **原始 tf 裸试(HVH/VHV 各一次)**:LEF 读入失败——
   `Error: Line 264325, Cannot find via 'VIA12_square'. (LEFR-004)`。两变体同样。
2. **官方修正路线**:
   - `GenPRTF.tcl -VRP 0.14 -GcellMultiple 3 -CellHeight 9`(全部为官方文档
     允许值:VRP "0.135|0.13|0.14"、GcellMultiple "3|4"、CellHeight "7|9|12")
     重生成双变体 tf → 仅改 50 行:unit 0.135→0.140、gaunit 0.540→0.420、
     垂直层 pitch 0.135→0.14。输出在 `pdk28_bringup/prtf_gen/`,**原始交付未动**。
   - 补丁 LEF `pdk28_bringup/patch/sites_vias_bwp40p140.lef`:SITE core/gacore/
     bcore 三定义(依据见上表+patch/README.md)+ VIA12_square/slot/slotV 三定义
     (逐字复制自同交付家族 Cadence tlef tn28clpr002e1,仅取 via,未采用 tlef 路线)。
3. **建库**:补丁 tf + 补丁 LEF + cell LEF → HVH/VHV 双 NDM,零 Error。

### 变体选型:**HVH**(证据推翻前次"VHV"目录名推断)

双变体 tf 唯一实质差异是 M1/M2 pitch 互换:HVH = M1 pitch 0.1(横)/M2 0.14(纵);
VHV 相反。LEF 实测 TAPCELL 的 VSS 电源轨在 M1 上沿 x 横贯(y 仅 ±0.075)→
**M1 物理为横向 → HVH 匹配**。逻辑库 apt 目录名 "cell_frame_VHV_0d5_0" 是另一套
起层命名约定,以 pitch 实测为准。VHV NDM 同样已建,留作对照。

## 第四部分:【需要决策的事项】(按重要性)

1. **时钟周期目标**:10 ns 裕量 +7.65 过大。选项:a) 4 ns(裕量≈1.6,有优化压力,
   更接近真实 PPA);b) 5 ns(稳);c) 维持 10 ns 直到 P&R 通了再收。
   后果:定档影响后续所有 P&R/签核基线,建议早定。
2. **hold/removal 的 −0.01 级违例处理时点**:选项:a) 留给 P&R(常规;复位树 +
   hold fixing 一并做);b) DC 阶段 set_fix_hold 预修(会加 buffer,P&R 可能重做)。
   建议 a。
3. **NDM 变体确认**:HVH 已按 M1 pitch 实测选定,VHV 留档。若你有异议(比如后端
   习惯用 M2 起层命名),说一声;P&R 首跑前定死即可。
4. **ICC2 NDM 的时序视图**:本次冒烟为 frame-only(B.3 判据未含 .lib 挂接)。
   P&R 前需把 nldm .db 挂进 NDM(icc2_lm_shell read_db)或走 split-timing 流程,
   顺带把 IO 库 sefu9lm 建成第二个参考 NDM。属既定后续,不阻塞。
5. **sbocv 启用时点**:建议 PT 首跑就带(read_aocvm),DC 保持无 derate 基线。
