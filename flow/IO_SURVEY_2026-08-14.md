### 1.1 单元族(123 MACRO 全谱)

信号 pad 全部是**双向单元**(无纯输入/纯输出型),按 `P`+功能+驱动(mA)+`S`=Schmitt+`DGZ`+`_H/_V` 命名,尺寸一律 20×110µm、x-pitch 20µm(仅晶振 pad 50µm):

| 族 | 代表单元 | 说明 |
|---|---|---|
| 双向+下拉 | PDDW{04,08,12,16}DGZ_{H,V}_G | 三态输出+输入+使能控下拉,fail-safe |
| 双向+下拉+Schmitt | PDDW{04,08,12,16}**S**DGZ | SPI/复位输入首选 |
| 双向+上拉(+Schmitt) | PDUW{04,08,12,16}(S)DGZ | CS_N 首选(悬空默认未选中) |
| 限摆率变体 | PRDW/PRUW{08,12,16}(S)DGZ | EMI 敏感场景,本项目不需要 |
| 晶振 | PDXOEDG | 不用(时钟外供) |
| 模拟 IO/电源 | PDB3A*、PVDD/PVSS{1,2,3}A* 族 | 本项目纯数字,不用 |
| IO 电源地 | **PVDD2DGZ**(VDDPST)、**PVDD2POC**(上电控制)、**PVSS2DGZ**(VSSPST)、**PVSS3DGZ**(核+IO 共地) | POC 网经所有 pad 的 FEEDTHRU 端口沿环连通 |
| 核电源地 | **PVDD1DGZ**(VDD)、**PVSS1DGZ**(VSS) | |
| corner | PCORNER_G,110×110,CLASS ENDCAP | |
| filler | PFILLER{0005,05,1,5,10,20},宽 0.005~20µm | |
| 其他 | PRCUT(域间断轨)、PENDCAP、PCLAMP/PCLAMPC(ESD 钳位,CLASS BLOCK 100×22) | 单电源域用不到 PRCUT;PCLAMP 可选 |

### 1.2 RN 170A 的摆放硬规则(pad 环草案必须服从)

1. 数字功能 IO(或晶振)与 PVDD1DGZ/PVDD1ANA 之间 ≥3µm filler;
2. PVDD2DGZ 必须紧邻 PVDD2ANA——**该条针对含模拟域的设计**,纯数字域用 PVDD2DGZ+PVDD2POC 组合,以 databook 摆放章为准复核(待决项 D3);
3. 数字功能 IO 与 PCORNER 之间必须隔 PVSS2DGZ 或 PVSS3DGZ;
4. 每电源域负载电容 >20pF、上电 ramp >10µs(含义复核列待决项 D7);
5. 选用 PAD50 焊垫时 IO 两侧各加 2.5µm filler,PAD60 各 5µm。

## 任务 3:选型表与 pad 环草案

### 3.1 引脚—pad 选型(9 信号,与 docs/spi_interface_spec.md §1 一致)

| 引脚 | pad 单元 | 配置 | 上下拉 |
|---|---|---|---|
| SCLK / MOSI | PDDW04SDGZ_H_G | 输入(Schmitt) | 下拉 |
| CS_N | PDUW04SDGZ_H_G | 输入(Schmitt) | 上拉 |
| rst_n | PDDW04SDGZ_H_G | 输入(Schmitt) | 下拉(悬空=保持复位) |
| clk | PDDW04DGZ_H_G | 输入(非 Schmitt;167MHz 能力待 databook 复核,D2) |下拉 |
| MISO / scan_out / scan_valid / scan_last | PDDW04DGZ_H_G | 输出(4mA;线缆负载复核见 D2) | — |

### 3.2 电源 pad 预算(10 只)

| 单元 | 数量 | 理由 |
|---|---|---|
| PVDD1DGZ / PVSS1DGZ(核 0.9V) | 2 / 2 | 核功耗 ~16mW@6ns,双对足够 IR;对称分布东西/南北 |
| PVDD2DGZ(IO 1.8V) | 1 | 9 根低速信号,单只富余 |
| PVDD2POC | 1 | POC 网驱动,每域一只 |
| PVSS2DGZ | 2 | IO 地,兼任 corner 隔离(RN 规则 3) |
| PVSS3DGZ | 2 | 共地,补足另两个 corner 的隔离 |

合计 pad 槽位 19(9 信号+10 电源)+ 4×PCORNER。

### 3.3 摆放草案(阶段 C 细化)

西边:SCLK、CS_N、MOSI、MISO + PVSS2(SPI 集中一侧便于台架走线);北边:clk、rst_n + PVDD2、PVDD2POC + PVSS3;东边:scan_out、scan_valid、scan_last + PVDD1、PVSS1(读出与 SPI 分侧,降串扰);南边:PVDD1、PVSS1 + PVSS2、PVSS3。每边 4-5 槽,每个数字 IO 与 corner 之间按规则 3 保证 PVSS2/3 相邻,PVDD1 与数字 IO 之间垫 ≥3µm filler(规则 1)。

### 3.4 die 尺寸估算

焊垫选 **PAD50GU 单排**(外排):本设计 19 pad 摊到四边,每边内沿 ~465µm 只放 5 槽,焊垫中心距 ~90µm,远大于 50µm 交错焊距的设计初衷——**无需内排 PAD50NU,规避其 60.84µm 的 core 越出**,CUP 面积零占用。

估算式(单边):die 边长 = 2×PCORNER(110)+ max(内沿 pad 槽需求,core 边长 + 2×布线通道)。core 继承 R2 的 415µm;pad-to-core 通道按 25µm 计;槽需求 5×25µm=125µm ≪ core 项,不构成约束。

die 边长 ≈ 415 + 2×(110 + 25) = **685µm**;若 PAD50GU 的 29.16µm die 边越出需要额外边缘余量(待决项 D5,视 seal ring 规则),上界 685 + 2×30 = 745µm。**判定:die ≈ 0.69~0.75mm 见方,0.47~0.55mm²,约为 core-only(0.172mm²)的 2.7~3.2 倍,pad 环与 core 均衡,非 pad-limited。**

### 3.5 与现有 flow 的衔接点

- **tech 定义**:ICC2 走现有 PRTF tf(`tsmcn28_9lm4X2Y2RUTRDL.tf`,层定义齐),IO cell LEF 无 tech 段不构成缺口;IO 库需经 library manager 编 NDM(LEF+8 角 .db),与 65nm ref 库重建为同型操作;
- **金属方案配对**:GPIO LEF 端口最高用到 M7,tf 栈 9M_4X2Y2R 完整覆盖,bond pad 恰为 9M_4X2Y2R 交付——三者一致,判定配对成立;
- **DC/PT**:IO .db 直接入 link library;pad 例化层 dont_touch;
- **LVS**:IO 库 .spi 并入 CDL 源;GDS 合并序 core+IO+bond pad;
- **DRC**:主 deck(1P12M 适配 9M 栈)已在 R1/R2 验证,AP/CB/RV 层规则将随 bond pad 首次激活(与 D5/D6 联动);
- **MMMC**:IO 8 角与核库角名严格同构(tt0p9/ffg0p99/ssg0p81 × 温度),FUNC_WC=ssg0p81v1p62vm40c、FUNC_BC=ffg0p99v1p98v125c 直接配对,无缺角。
