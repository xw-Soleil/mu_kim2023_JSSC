## 第一部分:Stage D — via 补丁是否多余:**不多余,保持原样**

| 步骤 | 结果 |
|---|---|
| D.1 重生成 tf 里 grep 三个 via | `VIA12_square/slot/slotV`:HVH=0,VHV=0——**零出现** |
| D.2 原始 vs 重生成 tf 的 ContactCode 清单 | **逐条相同**(各 117 条,diff 空)——GenPRTF 不改 via 段 |
| D.3 GenPRTF.tcl 的 via 处理 | 代码中 contact/via 相关行 **0 处**——只重写 Tile/pitch/implant |

无 LEF via 定义),补丁 3 SITE + 3 via 全部必要,不精简。

### E.2 Floorplan(s02)

### E.3 tap/endcap(65nm 做不到的事,本次落地)
- 间距核算(按任务要求重算):S=√(R²−H²),R=30(appnote 引 DRM LUP.6),
  本库行高 H=0.9 → S=29.986,2S=59.97 —— appnote 的 60 µm 建议对 bwp40p140
  成立(其 H=2.52 算例同样收敛到 60)。
- `create_tap_cells -distance 60 -pattern every_row`(`normal` 非法值,合法集
  every_row/every_other_row/stagger,取 appnote 原文 "on every row")。
- 实测:**TAPCELL 3,960 个**(495 行 × 8 列);列 x 坐标 39.87…429.35,
  **相邻列距 59.91–59.93 µm ≤ 60**,首列距核边 29.87 ≤ S ✓。
- **BOUNDARY_LEFT/RIGHT 各 495**(每行成对)。`create_boundary_cells` 可用但报
  deprecated(建议未来换 compile_boundary_cells,已记录)。

### E.4 电源网络
- VDD/VSS 命名网 + M9(横)/M8(纵)ring 1.6/0.8 + M1 follow-pin rail,
  PG shapes 504;floating wires/vias/cells 终检 **全 0**。
- 供电口物理 terminal:首跑遗漏(65nm eco02 教训段未抄全,RT-203 两口无形状),
  s07b 补上(M9 底段 1.6 µm 窗口),PINS 升为 59/59。

### E.5 Placement(s03,12 min)

### E.6 CTS(s04,~10 min×2 次)
- 时钟树:**sinks 23,907 / 10 级 / 543 repeater / global skew 0.18 ns /
  max insertion 0.32 ns**,trans/cap DRC 0。
- **复位树独立统计**(BFS 网表遍历;初版 all_fanout 方法漏数已标注):
  **571 个 buffer/inverter、7 级、覆盖 16,126 个 CDN 端点**——与时钟树分账,
  65nm Innovus 线 853 混 486 的教训兑现。
- **postCTS removal:全 MET,最差 +0.18**(DC 基线 −0.01 → 转正);recovery +8.02。
- 事故记录:首跑 `report_clock_trees` 非本版命令,死在 save 前,CTS 574 s 白跑;
  重构为"重活后立即 save,报告全包 catch"并重跑(教训固化进脚本)。

### E.7 Routing + 天线(s05 + s05b)
- route_auto + route_opt:118,513 nets,布线 DRC 0(当次检查)。
- **发现:define_antenna_rule 不随 save_lib 持久化**(新会话 report 为空)——
  首跑天线检查被路由器静默关闭("Turn off antenna since no rule is specified")。
  修复:每个布线会话重新 source;s05b 增量布线在规则激活状态下重跑:
  **天线违例 = 0,二极管插入 0 个**。
  判据说明:E.7 的"二极管应 >0 否则规则没生效"在本结果中需修正——规则生效有
  独立证据(7,138 字符规则报告 + 路由器识别 mode 1/2/4 + detail.antenna=true),
  违例为 0 所以无二极管可插,属诚实结果(小块、短网,合理)。

### E.8 postRoute 两遍优化(s06)
- 专用 hold-margin 选项不存在(probe 实测);回退:FUNC_BC hold uncertainty
  本 pass 内 0.05→0.10(**加严非放宽**),pass 后恢复 0.05。
- 结果:hold 违例 16→**0**,三组 Worst Hold 0.00。

### E.9 Chip finish(s07 + s07b + s07 重跑)
- **首跑门禁漏洞自查**:仅 parse setup/hold 的门禁放过了 113 条 DRC + 73 条

- s07b 修复:①增量布线 1 轮收敛 DRC 113→**0**、short 73→**0**;②补供电 terminal。
- s07 门禁加固为六项全 fail-closed 后重跑:
  **`PDE28_GATE setup_violations=0 hold_violations=0` +
  `drc=0 antenna=0 opens=0 shorts=0`** → 产物重新生成。
- 产物:GDS 146 MB(gdsout_4X2Y2R.map 映射)、DEF 148 MB、postroute.v 30 MB、
