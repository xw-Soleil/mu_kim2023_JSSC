# 28nm 第三轮:整芯片收官(SPI 配置接口 + pad 环 + bond pad + 独立签核)(2026-08-15)

目标来自教师要求:把 core 做成可流片形态的芯片——补上串行配置接口与完整的 IO pad 环、键合盘。本文是轮级汇总,证据细节在各阶段记录里,不重复。

## 四个阶段与产物

- **B(接口)**:SPI 式串行配置接口,`pde_chip_top_spi` 在 core 外包一层配置桥;协议与寄存器映射见 `docs/spi_interface_spec.md`。
- **C(综合)**:pad 级顶层 `pde_chip_pads`(9 只信号 GPIO 包住 SPI 顶层),`flow/dc28/synth28.tcl` 增加 pad 分支(IO 库 link-only、pad dont_touch、板级边界约束);运行 `dc28_pads_20260814`,6ns 收敛 WNS +1.46。
- **D(实现)**:ICC2 整芯片,新阶段脚本 `s02_floorplan_chip.tcl` + 条件化公共层;die 精确 685×685µm,21 IO pad + 4 corner + 145 IO filler + 21 CUP bond pad,六硬门(setup/hold/DRC/antenna/开路/短路)全零,利用率 0.7806,setup 裕量 +1.16ns@6ns。记录:`flow/FULLCHIP_28NM_2026-08-15.md`,运行 `icc2_28nm_chip_20260815c`。
- **E(签核)**:EDAServer 独立重验。PT 两角全零(24,016 端点 100% 覆盖,pad 时序弧入网);Calibre ANT 0;逻辑 DRC 以代工厂 IP 排除法收到 1,031 项且全部落入记录在案的豁免组;CN28_WIRE_BOND 装配 deck 首激活全零;LVS 158 万 MOS 全配、9 端口全对,PG 域残差全部具名根因、零未解释项。记录:`flow/SIGNOFF_CHIP_28NM_2026-08-15.md`。ICC2 侧两类豁免(PG opens、hairline shorts)均被签核正面仲裁闭环。

## 状态判定

教学目标"可流片形态"达成:接口、pad 环、键合盘、装配规则、独立签核全部就位。距真实流片的已知差距只有两类且均有明确归属:dummy fill(教师裁定不做,密度族违例记录在案)与 LVS CORRECT 判定(需下一轮网表建模演进,见下)。

## 裁掉与遗留

教师裁掉:AOCV 加严、dummy fill、5ns 重收敛。下一轮候选(按 SIGNOFF_CHIP §8):write_gds map 补齐 11 个 vendor 层、环总线按物理弧段建模(冲击 LVS CORRECT)、PG text 出流程正式化、PVSS3/PVSS2 的 ESD 供电覆盖对 databook 终确认。

## 本轮方法学沉淀(供后续轮次直接沿用)

代工厂 IP 的签核口径:vendor IO 内部以 datatype-0 NOUSE 层编码、对逻辑 deck 原生不可见,流出归一化会误点亮 → 逻辑 DRC 用 EXCLUDE CELL、LVS 用 BOX/FILTER、bond 复合区用专用装配 deck。工程纪律:对照实验先验证对照物内容;deck 只改工作副本并 diff 归档;所有传输双端 sha256。工具环境速查(含 EDAServer、v2lvs、calibre -query 用法)在 `local_artifacts/TOOLCHAIN.md`(不入库)。
