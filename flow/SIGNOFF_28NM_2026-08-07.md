### H.4 LVS(deck T-N28-CL-LS-002-C1 v1.0_3o——本项目首次 LVS)

来源网表:v2lvs v2015.2(`-v postroute.v -lsp/-s tcbn28hpcplusbwp40p140_110a.spi
-s0 VSS -s1 VDD`);v2lvs 告警:pde_tcu 模块存在大小写仅异的网名对
(n172/N172 类),deck 侧 CASE 敏感为 YES,记录在案。

**判定:INCORRECT(as-run)**。差异完整分解(证据链齐全):

1. **晶体管级 100% 匹配**:MN(nch_mac)772,988 / MP(pch_mac)773,038,两侧全
   配对,0 unmatched。网络 798,117 对匹配,仅 2+2 不匹配(见 3)。
2. **布局侧端口 0 个 vs 源侧 59 个**(57 信号 + VDD/VSS)。根因已定位:ICC2 经
   gdsout map 写出的顶层端口 text 落在 33;0 / 34;0(信号,即 M3/M4 drawing 层
   texttype 0)与 39;80(VDD/VSS);而 deck 只认 131–139(MxTXT)或 127;3x
   (GDS TEXT 记录逐条扫描 + deck TEXT LAYER 语句比对,双向证实;标准单元内部
   text 恰在 131;0/132;0,佐证库 view 用的是 TSMC text 约定,仅顶层端口走了
   PRTF map 的另一套)。VDD/VSS 因此无名,连带电源网无法配对。
3. **cfg_addr[3]/[5] 两网差异 = 端口缺名导致的拓扑歧义伪影,非物理缺陷**。
   证据链:唯一涉事实例 u_impl/U687 为 OAI31D0(A1/A2/A3 为可交换输入);DEF
   实测 A1=cfg_addr[5]、A2=cfg_addr[3]、A3=cfg_addr[4],与网表逐字一致(无引脚
   交换、无绕线交叉);两个端口网除对称输入外拓扑不可分,Calibre 自报
   "Ambiguity points were found and resolved arbitrarily";ICC2 check_lvs
   (对其网表)开路 0 短路 0。端口 text 命名恢复后该伪影应消失(待验证)。
4. **66,132 个源侧实例 unmatched** = FILL×61,182 + TAPCELL×3,960 +
   BOUNDARY×990。库 spice 中这些 subckt 为空(`.subckt … VDD VSS` / `.ends`,
   无器件),Calibre 将空 subckt 视为待配对 box,而布局侧其几何已并入井/电源轨、
   不产生实例。属账目性差异,不涉及任何器件。
5. 信息项:2,020 个源网 deep-short 合并为 417(井/衬底连通所致)。

**修复第二轮未执行**:准备在 LVS runset 副本追加三条 text 层映射(仿 deck 自身
127;3x 写法,将 33;0/34;0/39;80 声明为 M3/M4/M9 text)后重跑,被权限门拦截
(超出精度批准范围),按既定规则停止,转为第五部分决策项 ①。
